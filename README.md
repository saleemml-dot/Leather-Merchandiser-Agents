# Leather Merchandiser AI

AI multi-agent system that acts as a merchandiser for finished leather exports worldwide.  
It handles buyer research, personalized outreach, qualification, and order support so the owner can focus on product development.

## Features
- Global buyer research (importers, brands, traders)
- Personalized cold outreach emails
- Lead qualification
- Order support & follow-up
- Designed for finished leather exporters

## Tech Stack
- CrewAI / LangGraph (multi-agent)
- Python
- OpenAI / other LLMs
